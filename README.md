# HawkTimer 鷹眼計時

Windows 透明桌面蕃茄鐘，時間到時播放 GIF 與提醒文字，並可透過 ntfy 發送 Android 通知。

## 功能

- 每次啟動會在背景檢查 GitHub 最新正式版本；發現新版時可選擇下載 MSI，也可從右鍵選單手動檢查。請關閉 HawkTimer 後再執行下載的安裝檔。

- 點「縮小」可收納至 Windows 系統匣，倒數仍持續；雙擊圖示或按右鍵選「顯示計時器」可恢復。系統匣選單可結束程式。

- 透明背景及置頂計時視窗，可拖曳角色移動，右鍵開啟選單；常駐角色可替換 GIF，並可在設定中調整視窗大小（85–160%）和人物大小（50–150%）；放大人物時視窗會視需要擴大以避免裁切。
- 點擊主畫面的時間即可輸入「分:秒」，按 Enter 儲存或 Esc 取消；也可在設定中調整。
- 設定專注時間（最短 1 秒）、電腦提示音與 ntfy 通知；設定和視窗位置會自動保存。
- 支援選擇 GIF 或圖片作為提醒動畫；每次隨機選取一則自訂文字，逐字顯示。
- 手機持續響鈴需在 Android ntfy 的訂閱通知設定中啟用。

## 安裝

前往 [Releases](https://github.com/funny4875/HawkTimer/releases) 下載 MSI，安裝後可從桌面或開始選單啟動。程式安裝於 `%LOCALAPPDATA%\HawkTimer`，`message.txt` 位於同一資料夾。MSI 未經數位簽章。

## 從原始碼執行

需要 Windows、Python 3.10 以上。於專案資料夾執行：

```powershell
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

開啟設定，將 ntfy 主題改為手機訂閱的主題。主題預設值僅供示範，未受保護的 ntfy 主題只要知道名稱便可能被讀取或發布；請勿傳送私人資訊。設定儲存於 `%APPDATA%\HawkPomodoro\settings.json`，倒數進度不會保存。計時需保持程式及電腦運行，手機通知需連網。

程式使用 Windows 信任存放區驗證 HTTPS 憑證。內附角色動圖為 AI 生成的同人素材；角色權利屬原權利人。
## 自訂提醒文字

編輯程式所在資料夾的 `message.txt`（UTF-8 編碼），用單獨一行 `========` 分隔訊息；同一則訊息可以包含多行。程式每次時間到時重新讀取檔案，隨機挑選一則，畫面與 ntfy 發送相同內容。也可以在設定視窗編輯並儲存，或按「文字檔」開啟編輯。提醒框會依內容加長，超出螢幕時可捲動。訊息過長時可能超出 ntfy 的訊息長度限制。首次啟動若沒有文字檔，會使用原有設定建立。

## Google Calendar 多帳號行程

1. 在 Google Cloud 專案啟用 Google Calendar API，設定 OAuth 同意畫面，建立「桌面應用程式」OAuth 用戶端，並下載 JSON。若應用程式仍處於測試狀態，請將每個要連結的 Google 帳號加入測試使用者。
2. 開啟 HawkTimer「設定」→「Google Calendar 設定」，匯入 JSON，再按「新增／重新授權帳號」，在瀏覽器分別登入與授權每個帳號。若 Google 顯示未經驗證畫面，需依專案的發布與驗證狀態處理。
3. 可在相同設定視窗移除帳號，並設定行程開始前提醒是否同時透過現有 ntfy 主題發送手機通知。計時器手機通知與行程手機通知分別設定。
4. 從設定或右鍵選單開啟「行程查詢」，輸入起迄日期時間即可列出各帳號行程；若有帳號查詢失敗，結果會明確顯示，不能將其視為空閒。

程式運行且網路可用時，每分鐘同步行程：有時間的行程在開始前約 10 分鐘顯示提醒，全天行程顯示在查詢與每日清單中；每天 08:00 顯示未來七天行程，不發送手機通知。若程式在 08:00 後才開啟，會在當日成功同步後補顯示。程式關閉、電腦休眠或離線時無法準時提醒；重新連線後會在時間仍未開始時補提醒。多個帳號共享行事曆時，同一行程可能顯示多次。

OAuth 設定與各帳號授權資料以 Windows DPAPI 保護，儲存在目前 Windows 使用者的 `%APPDATA%\HawkPomodoro\calendar`，不會打包進 MSI。移除帳號會刪除本機授權資料；若需要撤銷 Google 授權，請另至 Google 帳戶的第三方存取設定操作。
